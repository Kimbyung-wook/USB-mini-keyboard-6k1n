# 미니 매크로 키보드 사용 설명서

키 6개 + 노브 1개 USB 매크로 키보드와, 키마다 문자열을 넣는 PC 설정 프로그램(GUI) 사용법.

| 항목 | 내용 |
|---|---|
| 대상 버전 | 펌웨어 **v1.6.0**, 설정 프로그램 **GUI 1.6.0** |
| 키보드 | **MK6K1N**(6키 + 노브, LED 1개), **MK6K1NL**(6키 + 노브, 키마다 LED). 사용법 같음, LED 표시만 조금 다름([핀 배치](PINMAP.md)) |
| 펌웨어 수정·빌드 | 이 문서가 아니라 [firmware/macro_keyboard/README.md](../firmware/macro_keyboard/README.md) 참고 |

## 1. 한눈에 보기

```
 ┌───────────────────────────────┐
 │  [A]   [B]   [C]      (노브)  │   노브: 돌리기(시계/반시계) + 누르기
 │  [D]   [E]   [F]       LED    │
 └───────────────[USB]───────────┘
```

- **슬롯 9개**: 키 A~F + 노브 세 동작(시계 방향 한 칸, 반시계 방향 한 칸, 누르기)에 문자열 하나씩
- 키를 누르면 저장된 문자열이 **키보드로 타이핑한 것처럼** 입력됨
  - 글자(`Hello{ENTER}`), 단축키(`{CTRL+C}`), 대기(`{DELAY:500}`) 모두 가능
- 문자열은 PC의 **설정 프로그램(GUI)**으로 넣고 고침
  - 키보드에 저장되므로 GUI가 없는 PC에서도 그대로 동작함
- **패턴 암호**를 정하면 꽂을 때마다 잠김. 키와 노브로 암호를 입력해야 사용 가능

### LED 색 요약

| LED | 뜻 |
|---|---|
| 꺼짐 + 3초마다 빨강 짧게 깜빡 | **잠김**. 키를 눌러도 반응 없음 |
| 빨강 계속 켜짐 | **패턴 암호 입력 중**(풀기 또는 다시 잠그기). **MK6K1NL**은 누른 키의 LED가 잠깐 꺼짐(노브는 전체가 잠깐 꺼짐) |
| 빨강 계속 깜빡 (약 0.5초 간격) | **차단**. 암호 5번 틀림. 다시 꽂아야 함 |
| 파랑 | **사용 가능**(잠금 풀림 또는 패턴 암호 안 씀) |
| 초록 (잠깐) | 문자열 입력 중. **MK6K1NL**은 누른 키의 LED만 초록, 나머지는 파랑(노브로 입력할 때는 모두 초록) |
| 흰색 (0.3초) | GUI에서 설정 저장함 |
| 보라 | 펌웨어 업데이트 모드로 들어가는 중 |

- MK6K1NL(키마다 LED): 초록 외의 모든 표시는 6개 LED가 같은 색

## 2. 처음 사용하기

1. 키보드를 PC의 USB 포트에 꽂음. **이때 아무 키도 누르지 않음**
   - 키 D나 노브를 누른 채 꽂으면 펌웨어 업데이트 모드로 들어감([8장](#8-펌웨어-업데이트))
2. Windows가 자동으로 인식함. 드라이버 설치 필요 없음
3. 설정 프로그램 실행([5장](#5-설정-프로그램gui-사용-방법)). 상단에 `● 연결됨`이 보이면 준비 완료
4. 키를 고르고 문자열 입력 → **[장치에 저장]**. LED가 흰색으로 잠깐 빛나면 저장됨
5. 메모장을 열고 키를 눌러 입력되는지 확인

> **한/영 전환 주의**
> - 키보드는 영문 자판 기준으로 키를 보냄
> - Windows가 **한글 입력 상태**이면 `Hello`가 `ㅗ디ㅣㅐ`처럼 나옴
> - 입력받을 창을 **영문 입력 상태**로 두고 사용

## 3. 키보드 사용 방법

### 키 A~F

- 누르면 저장된 문자열이 바로 입력됨
- 입력 중에 다른 키를 눌러도 됨. 최대 8개까지 대기했다가 순서대로 입력함
- 빈 키: 아무것도 입력되지 않음(LED만 초록으로 잠깐 켜짐)

### 노브

| 동작 | 입력되는 것 |
|---|---|
| 시계 방향으로 한 칸 | "노브 시계 방향" 문자열 (예: `{RIGHT}`, `{DOWN}`) |
| 반시계 방향으로 한 칸 | "노브 반시계 방향" 문자열 (예: `{LEFT}`, `{UP}`) |
| 짧게 누르기 | "노브 누르기" 문자열 (예: `{ENTER}`) |
| **2초 누르고 있기** | 패턴 암호 입력 시작([4장](#4-패턴-암호-잠금)). 패턴 암호를 쓸 때만 |

- 한 칸(딸깍) 돌릴 때마다 한 번씩 입력됨
- 패턴 암호를 쓰면 노브 누르기 문자열은 **뗄 때** 입력됨
  - 이유: 2초 넘게 누르면 문자열 대신 패턴 암호 입력이 시작되기 때문

### Caps Lock

- Caps Lock 상태와 관계없이 저장한 대소문자 그대로 입력됨(`Hello` → 항상 `Hello`)

## 4. 패턴 암호 (잠금)

- 목적: 주변 사람이 키를 눌러 저장된 문자열을 쓰지 못하게 잠금
- 암호: 키와 노브를 정해진 순서로 입력하는 것

### 패턴 암호 정하기

1. GUI의 **패턴 암호** 칸에서 키/노브 버튼을 순서대로 누름
   - 버튼: `A`~`F`(키), `↻`(노브 시계 방향 한 칸), `↺`(노브 반시계 방향 한 칸), `●`(노브 누르기)
   - **2~8단계**. 예: `A → B → C → ↻`
   - 2~3단계는 펌웨어 v1.6.0 이상. 짧을수록 맞히기 쉬우므로 4단계 이상 권장
   - 잘못 눌렀으면 **[⌫ 한 칸 지우기]**, 처음부터는 **[모두 지우기]**
2. **[장치에 저장]** 누름
3. 저장 직후에는 잠기지 않음. **다음에 꽂을 때부터** 잠김

![패턴 암호 칸](images/gui_lock.png)

- 저장 공간 사용: `2 + 단계 수`바이트(4단계면 6바이트). 그만큼 문자열을 적게 넣을 수 있음

### 잠금 풀기

1. 꽂으면 **잠김** 상태(LED 꺼짐, 3초마다 빨강 짧게 깜빡). 키를 눌러도 반응 없음
2. **노브를 2초 누르고 있다가** LED가 **빨강으로 계속 켜지면** 놓음
3. 패턴 암호를 순서대로 입력. 입력 중에는 아무것도 타이핑되지 않음
4. 맞으면 LED **파랑** → 평소처럼 사용

- **틀리면**: 다시 잠김. 노브 2초부터 다시 시작
- 빨강 켜진 채 **10초 동안 입력 없음**: 취소되고 잠김으로 돌아감. 틀린 횟수에 안 들어감
- **5번 틀리면 차단**: 빨강 계속 깜빡, 아무 입력도 안 받음. USB를 뺐다 다시 꽂으면 재시도 가능
- 꽂는 순간 노브를 누르고 있으면 펌웨어 업데이트 모드로 들어감. 노브 2초 누르기는 **꽂은 다음에** 함

### 다시 잠그기

- 자리를 비울 때 뽑지 않고 잠그는 방법

1. 풀린 상태(파랑)에서 **노브를 2초 누르고 있음** → LED 빨강 계속 켜짐
2. 같은 패턴 암호 입력 → 잠김(꺼짐 + 가끔 빨강 깜빡)

- 틀리면 잠기지 않고 파랑으로 돌아감
- 다시 잠그기를 **5번 틀리면** 그냥 잠김
  - 차단이 아니라 잠김이므로 노브 2초 + 맞는 암호로 바로 풀 수 있음
- 10초 동안 입력 없으면 취소, 파랑으로 돌아감
- 뺐다가 다시 꽂아도 잠김

### 자동 잠금

- 풀린 뒤 한동안 안 쓰면 저절로 잠김(펌웨어 v1.4 이상)

1. GUI 패턴 암호 칸 아래 **자동 잠금**에 분(1~255) 입력. **0분 = 자동 잠금 안 함**
2. **[장치에 저장]** 누름

- 잠기는 조건: 그 시간 동안 **키/노브 입력 없음** + GUI 읽기·저장·테스트 입력도 없음
  - GUI를 켜 두기만 하는 것은 입력으로 치지 않음
- 잠기면 GUI 화면의 설정도 지워짐(저장 안 한 편집 포함). 오래 편집할 때는 중간에 저장
- 패턴 암호가 있을 때만 사용 가능. 패턴 암호를 지우면 자동 잠금도 0분이 됨
- 저장 공간 3바이트 사용

### 잠금 끄기

1. GUI 패턴 암호 칸에서 **[모두 지우기]**
2. **[장치에 저장]**

- 이후에는 꽂자마자 파랑으로 켜짐

### 패턴 암호를 잊었을 때

- 방법: **잠긴 상태 그대로** GUI에서 새 설정을 저장

1. 키보드를 꽂고 GUI 실행. 상단에 `🔒 잠김` 표시
2. 새로 쓸 문자열 입력. 패턴 암호 칸은 비우거나 새 암호 입력
3. **[장치에 저장]** → "기존 문자열과 패턴 암호를 모두 지웁니다" 경고 → 확인하면 저장됨

- **기존 문자열은 되찾을 수 없음**. 잠긴 키보드의 내용을 못 읽게 하는 것이 이 기능의 목적
- 펌웨어를 다시 올려도 문자열과 패턴 암호는 지워지지 않음. 잊었을 때는 위 방법 사용
- 평소 [JSON 내보내기](#백업-json-내보내기--불러오기)로 백업해 두면 다시 넣기 쉬움

### 보안 수준

- 막는 것: 주변 사람이 키를 눌러 보거나 GUI로 내용을 읽어 가는 것
- 못 막는 것: 키보드를 가져가 펌웨어를 새로 굽는 등 작정한 공격
- **비밀번호처럼 민감한 문자열은 넣지 않는 것**을 권장

## 5. 설정 프로그램(GUI) 사용 방법

### 실행

- 배포된 **`MacroKeyboardConfig.exe`** 실행. Python 설치 필요 없음
- 저장소에서 바로 실행: `gui\.venv\Scripts\python -m gui` (설치 방법은 [gui/README.md](../gui/README.md))
- 키보드가 꽂혀 있으면 자동 연결. 실행 후에 꽂아도 2초 안에 연결됨

### 화면 구성

![설정 프로그램 화면](images/gui_main.png)

- 위에서부터 차례로:

| 영역 | 하는 일 |
|---|---|
| **연결 막대** (맨 위 세 줄) | 연결·잠금 상태, 보드와 저장 용량, 펌웨어 버전. 오른쪽에 [연결 끊기] [새로고침] [펌웨어 업데이트] |
| **키 / 노브 선택** | 키보드 모양 그대로의 버튼. 누르면 그 슬롯 편집. 버튼마다 글자 수와 문자열 앞부분 표시 |
| **패턴 암호** | 패턴 암호·자동 잠금 시간 설정, 잠금 사용법 표시([4장](#4-패턴-암호-잠금)) |
| **편집기** | 고른 슬롯의 문자열 편집. 위쪽 버튼으로 특수 키 삽입, 아래에 문법 검사 결과와 문법 요약 |
| **저장 용량** | 전체 글자 수, 더 넣을 수 있는 글자 수, 사용 바이트 |
| **아래 버튼** | [장치에서 읽기] [장치에 저장] [테스트 입력] [JSON 내보내기] [JSON 불러오기]. 맨 아래 오른쪽은 프로그램 버전 |

### 연결 막대

![연결 막대: 풀린 상태](images/gui_connected.png)

![연결 막대: 잠긴 상태](images/gui_locked.png)

| 표시 | 뜻 |
|---|---|
| `○ 연결 안 됨` | 키보드 없음. 꽂으면 자동 연결. [연결]을 눌러도 됨 |
| `● 연결됨 - 잠금 풀림` / `● 연결됨 - 잠금 안 씀` | 사용 가능. 패턴 암호가 있으면 "잠금 풀림", 없으면 "잠금 안 씀" |
| `🔒 잠김 - 키보드에서 노브를 2초 누른 뒤 패턴 암호를 입력하세요` | 키보드 잠김. 키보드에서 풀면 2초 안에 자동으로 설정을 읽어 옴 |
| `🔒 잠김 - 5번 틀려서 입력을 막았습니다. 키보드를 다시 꽂으세요` | 차단 상태. 키보드를 다시 꽂음 |

- 연결되면 아래 두 줄에 표시:
  - **보드와 저장 용량**: `MK6K1N (키 6 + 노브 1) / 용량 128바이트`
  - **펌웨어 버전과 빌드 날짜**: `펌웨어 v1.4.0 (빌드 2026-10-27 09:00)`
- 보드 정보를 안 보내는 펌웨어(v1.2.x 이하): 보드 뒤에 `· 보드 정보 없음` 붙음
- **[새로고침]**: 키보드 상태를 바로 다시 확인

### 연결되지 않았을 때는 아무것도 보이지 않습니다

- 보안상, 문자열과 패턴 암호는 **연결 + 잠금 풀림** 상태에서 키보드에서 읽어 온 것만 화면에 보임
- 키보드를 뽑거나 키보드에서 다시 잠그면 화면 내용이 **지워짐**(저장 안 한 편집 포함). 고친 내용은 먼저 저장
- 연결 안 된 동안: 편집기, 패턴 암호, JSON 버튼 꺼짐
- 다시 연결되어 풀리면 자동으로 다시 읽어 옴

### 문자열 편집하기

1. **장치 그림**에서 고칠 키나 노브 동작 누름(버튼에 글자 수와 미리보기 표시)
2. 아래 **편집기**에 문자열 입력. 문법은 [6장](#6-문자열-쓰는-법-매크로-문법) 참고
   - 편집기 위 버튼(`{ENTER}`, `{TAB}`, `{DELAY:100}` 등)과 **[조합키 ▾]**, **[특수 키 ▾]** 메뉴로 자주 쓰는 표기 삽입
   - 입력 즉시 문법 검사. 잘못된 곳은 빨간 밑줄, 아래에 몇 행 몇 열이 왜 틀렸는지 표시
3. 표시 확인
   - 저장 안 한 슬롯: 버튼에 `*`
   - 문법 틀린 슬롯: 빨간 글씨
   - 창 제목에도 `*` 붙음

### 저장 용량

- 전체 **128바이트**. 9개 슬롯 합계 최대 **102자**, 패턴 암호를 쓰면 그만큼 줄어듦
- 아래 막대에 `N자 입력 · M자 더 입력 가능` 표시
- 키마다 길이는 자유롭게 나눠 씀(예: 한 키에 40자, 다른 키에 5자)
- `{ENTER}` 같은 표기도 **쓴 글자 수만큼** 차지함(`{ENTER}` = 7자)
- 용량 초과: 막대가 빨간색, **[장치에 저장]** 꺼짐 → 문자열을 줄임

### 장치에 저장

- **[장치에 저장]**: 9개 슬롯과 패턴 암호를 한꺼번에 저장
- 저장 전 검사: 문법, 용량, 패턴 암호(2~8단계, v1.5.x 이하 펌웨어는 4~8단계). 문제가 있으면 알려 주고 저장 안 함
- 확인창에서 [예] → 저장, 키보드 LED 흰색으로 잠깐 빛남
- 키보드가 문자열 입력 중이면 잠시 기다렸다가 저장함

### 장치에서 읽기

- **[장치에서 읽기]**: 키보드에 저장된 내용을 다시 불러옴
- 화면에서 고치던 내용이 지워지므로 먼저 확인을 물음
- 저장된 설정이 없으면(새 키보드 등) 빈 슬롯으로 시작

### 테스트 입력

- 키를 누르지 않고 선택한 슬롯이 제대로 입력되는지 시험

1. 시험할 슬롯을 고르고 **[테스트 입력]** 누름
2. 확인하면 **3초 카운트다운** 시작. 그동안 입력받을 창(예: 메모장) 클릭
3. 키보드가 그 슬롯의 문자열을 입력함

- 키보드에 **저장된** 내용이 입력됨. 고친 내용을 시험하려면 먼저 저장

### 백업 (JSON 내보내기 / 불러오기)

- **[JSON 내보내기]**: 9개 슬롯의 문자열을 `.json` 파일로 저장
- **[JSON 불러오기]**: 저장해 둔 파일을 화면에 불러옴. 키보드에 넣으려면 이어서 **[장치에 저장]**
- **패턴 암호는 백업 파일에 들어가지 않음**. 불러와도 화면의 패턴 암호는 그대로
- 키보드가 연결되어 있을 때만 사용 가능

### 종료

- 저장 안 한 편집이 있으면 종료할 때 확인을 물음

## 6. 문자열 쓰는 법 (매크로 문법)

- 일반 글자는 그대로, `{ }` 안에 쓴 것은 특수 키나 동작으로 입력됨

| 쓰는 법 | 입력되는 것 | 예 |
|---|---|---|
| 영문, 숫자, 기호 | 그대로 | `Hello, World!` |
| 줄바꿈 (편집기에서 Enter) | Enter 키 | |
| `{ENTER}` `{TAB}` `{ESC}` `{BS}` `{DEL}` `{SPACE}` | Enter, Tab, Esc, Backspace, Delete, 스페이스 | `id{TAB}name{ENTER}` |
| `{UP}` `{DOWN}` `{LEFT}` `{RIGHT}` | 방향키 | 노브에 `{UP}` / `{DOWN}` |
| `{HOME}` `{END}` `{PGUP}` `{PGDN}` `{INS}` | Home, End, Page Up, Page Down, Insert | |
| `{F1}` ~ `{F12}` | 기능 키 | `{F5}` (새로고침) |
| `{CTRL+C}` `{ALT+TAB}` `{WIN+R}` | 조합키 | `{CTRL+S}` (저장) |
| `{CTRL+SHIFT+ESC}` | 수식키 여러 개 조합 | 작업 관리자 |
| `{DELAY:500}` | 0.5초 기다리기 (1~10000밀리초) | `{WIN+R}{DELAY:300}notepad{ENTER}` |
| `{{` / `}}` | 글자 `{` / `}` | `{{OK}}` → `{OK}` |

- 수식키: `CTRL`, `SHIFT`, `ALT`, `WIN`. 마지막에 글자 하나나 키 이름
- `+` 글자와 조합: `{CTRL++}`
- 키 이름은 대소문자 구분 안 함(`{enter}`도 됨)
- **한글 등 영문이 아닌 글자는 넣을 수 없음**. 미국(US) 자판 기준으로 입력됨

**예시**

| 하고 싶은 것 | 문자열 |
|---|---|
| 이메일 주소 입력 | `myname@example.com` |
| 인사말 두 줄 (영문만 가능) | `Hello,{ENTER}Thank you.` |
| 메모장 열기 | `{WIN+R}{DELAY:300}notepad{ENTER}` |
| 복사 / 붙여넣기 | `{CTRL+C}` / `{CTRL+V}` |
| 창 전환 | `{ALT+TAB}` |
| 노브로 위/아래 이동 | 시계 방향 `{DOWN}`, 반시계 방향 `{UP}` |

## 7. 문제가 생겼을 때

| 증상 | 확인할 것 |
|---|---|
| 키를 눌러도 입력 안 됨, LED 꺼짐 (가끔 빨강 깜빡) | 고장 아님, **잠김** 상태. 노브 2초 누른 뒤 패턴 암호 입력 |
| LED 빨강 계속 깜빡, 반응 없음 | 암호 5번 틀려 **차단**됨. USB 다시 꽂기 |
| 영문 대신 `ㅗ디ㅣㅐ`처럼 한글이 나옴 | 입력받는 창이 한글 입력 상태. 한/영 키로 영문 전환 |
| LED 초록으로 켜진 채 키를 눌러도 입력 안 됨 (KVM 전환, PC 절전 해제 뒤) | 펌웨어 v1.4.0 이하에서 입력 중 USB가 끊기면 생기던 문제. 다시 꽂으면 풀림. [v1.4.1 이상으로 업데이트](#8-펌웨어-업데이트)하면 안 생김. v1.4.1부터는 입력 중 전환되면 남은 문자열을 버림(다른 PC에 이어서 입력 안 함) |
| 글자가 일부 빠지거나 순서가 꼬임 | 프로그램이 입력을 늦게 받음. 문자열 중간에 `{DELAY:100}` 추가 |
| 단축키가 안 먹음 (예: `{WIN+R}` 뒤 글자가 사라짐) | 창이 뜨기 전에 글자가 입력됨. `{DELAY:300}`처럼 대기 추가 |
| GUI가 `○ 연결 안 됨`에서 안 바뀜 | USB 다시 꽂기. 다른 설정 프로그램 창이 열려 있으면 닫기 |
| 꽂았는데 LED가 전혀 안 켜지고 키보드로도 인식 안 됨 | 키 D나 노브를 누른 채 꽂아 펌웨어 업데이트 모드로 들어감. 아무것도 누르지 않고 다시 꽂기 |
| [장치에 저장]이 꺼져 있음 | 용량 초과(막대 빨간색), 패턴 암호 2단계 미만, 또는 키보드 연결 안 됨 |
| 펌웨어 업데이트에서 "60초 안에 칩을 찾지 못했습니다" | 뽑았다가 키 D를 누른 채 꽂고, 칩이 목록에 나타나면 [장입] 다시 누름. WCHISPTool이 열려 있으면 닫기 |
| GUI에서 "펌웨어 v1.0은 패턴 암호를 지원하지 않습니다" | 펌웨어가 오래됨. [펌웨어 업데이트](#8-펌웨어-업데이트) 또는 패턴 암호 지우기 |
| 자동 잠금 칸이 꺼져 있음 ("펌웨어 1.4.0 이상 필요") | 펌웨어 v1.3 이하. [펌웨어 업데이트](#8-펌웨어-업데이트). 패턴 암호가 없을 때도 꺼짐 |
| 편집하던 내용이 갑자기 지워지고 `🔒 잠김`이 됨 | [자동 잠금](#자동-잠금) 시간 지남. 풀고 다시 읽어 오기. 오래 편집할 때는 중간에 저장 |
| 패턴 암호를 잊음 | [패턴 암호를 잊었을 때](#패턴-암호를-잊었을-때) 참고 |

- 기술적인 문제 해결: [docs/TROUBLESHOOTING.md](TROUBLESHOOTING.md)

## 8. 펌웨어 업데이트

- 새 펌웨어 파일(`.hex`)을 받았을 때만 필요
- 문자열과 패턴 암호는 펌웨어를 바꿔도 그대로 남음

### GUI에서 올리기 (권장)

![펌웨어 업데이트 창](images/gui_firmware.png)

1. 키보드를 꽂고 GUI에서 **잠금 푼 상태**(`● 연결됨`)로 둠
2. 상단 **[펌웨어 업데이트]** 누름
3. 창 맨 위 **장입할 보드** 확인 후 펌웨어 파일(`.hex`) 선택
   - 저장소에서 빌드한 그 보드의 파일(예: `macro_keyboard-MK6K1NL.hex`)이 있으면 미리 골라져 있음. 파일을 골라도 바로 올리지는 않음
   - 장입할 보드: 연결되어 있던 키보드(예: `MK6K1NL · 6키 + 노브 1개, 키마다 LED (CH552G)`)가 골라져 있고, 아래에 업데이트 모드 진입 방법 표시
   - **처음 설치하는 키보드**(공장 펌웨어)나 보드 정보를 안 보내는 키보드: `⚠ 연결된 키보드를 식별할 수 없습니다` 표시 → 장입할 보드를 직접 고름
     - 안내에 그 보드의 공장 펌웨어 진입 방법 표시(MK6K1N: 키 E, MK6K1NL: D+ 풀업 저항)
     - [장입]을 누르면 고른 보드가 맞는지 한 번 물음
   - 파일 아래에 크기와 **어느 키보드용인지** 표시(예: `✔ 8795 / 14336바이트 (61%) · MK6K1NL용 (CH552) v1.6.0`)
     - 칩 용량보다 크거나 다른 칩용이면 올릴 수 없음
     - 다른 키보드용이거나 식별 정보가 없는 펌웨어(v1.2.x 이하): `⚠` 표시, [장입] 때 한 번 더 물음
4. **[업데이트 모드로 전환]** 누름 → 업데이트 모드(보라색 LED), **인식된 칩** 목록에 나타남
   - 칩마다 **파트 번호**(예: `CH552`), **시리얼 번호**(칩 고유 ID, 예: `7D-E2-0F-BD`), 부트로더 버전 표시
   - 목록은 1초마다 자동 갱신. [다시 검색]으로 바로 확인 가능
   - 방금 GUI에 연결되어 있던 키보드는 시리얼 번호 옆에 `(방금 연결된 키보드)` 표시(펌웨어 v1.3 이상)
5. 목록에 칩이 하나, `장입할 준비가 되었습니다` 표시되면 **[장입]** 누름
6. 진행 막대가 끝까지 차고 `✔ 장입 완료`가 나오면 **[닫기]** 누름
   - GUI가 다시 연결하고, 연결 막대에 새 펌웨어 버전과 빌드 날짜 표시

**잠겨 있거나 연결 안 된 키보드**

- 4번에서 "키 D를 누른 채 다시 꽂으세요" 안내가 나옴
- 뽑았다가 **키 D를 누른 채** 다시 꽂으면 목록에 칩이 나타남

**[장입]이 눌리지 않는 경우**

- 목록에 칩이 없을 때
- 칩이 **두 개 이상**일 때: 어느 칩에 올릴지 알 수 없음. 장입할 키보드 하나만 남김
- 칩이 고른 보드의 칩(MK6K1N, MK6K1NL은 CH552)이 아닐 때
- 고른 펌웨어가 다른 칩용일 때

**주의**

- 업로드 중에는 키보드를 뽑지 않음
- 중간에 실패하거나 [취소]했으면 키 D를 누른 채 꽂고 다시 시도. 업데이트 모드는 펌웨어와 관계없이 항상 진입 가능
- WCHISPTool 같은 다른 업로드 프로그램은 닫아 둠
- 키 D가 안 되면 **노브를 누른 채** 꽂아도 됨

### 스크립트로 올리기

- 업데이트 모드는 몇 초만 유지되므로 순서가 중요함

1. 저장소 폴더에서 스크립트를 먼저 실행

   ```powershell
   powershell -ExecutionPolicy Bypass -File tools\flash.ps1 -Hex firmware\macro_keyboard\build\macro_keyboard.ino.hex
   ```

2. 키보드를 **키 D를 누른 채** 꽂음
3. `Verify complete!!!`와 `Reset OK`가 나오면 완료

## 9. 사양

| 항목 | 값 |
|---|---|
| 입력 | 키 6개, 노브 1개 (돌리기 양방향 + 누르기) → 문자열 9개 |
| 저장 용량 | 128바이트 (문자열 합계 최대 102자, 패턴 암호는 `2 + 단계 수`바이트, 자동 잠금은 3바이트) |
| 패턴 암호 | 2~8단계(v1.6.0부터, 그 전에는 4~8단계), 키 A~F와 노브 동작 사용. 노브 2초 누르기로 입력 시작, 풀기 5회 실패 시 차단, 입력 없으면 10초 후 취소 |
| 자동 잠금 | 풀린 뒤 0~255분 동안 입력이 없으면 잠김 (0분 = 안 함, 펌웨어 v1.4 이상) |
| 입력 가능한 글자 | 영문, 숫자, 기호(ASCII), 특수 키, 조합키, 대기 |
| 연결 | USB 하나로 키 입력, 설정, 펌웨어 업데이트 |
| PC 프로그램 | Windows, `MacroKeyboardConfig.exe` |
| 칩 | CH552G |
